# Flock Energy Peak Load Calculation

Shows how a +1°C change on AC settings lowers peak load on the grid. Estimates for explanation only, not real utility data.

Pages: `/` calculator, `/calculation` how it is calculated, `/impact` impact.

```bash
npm install
npm run dev     # http://localhost:5173
npm test
npm run build   # output in dist/
```

Deploys on Vercel as a Vite project (build `npm run build`, output `dist`). `vercel.json` sends every path to the app.
